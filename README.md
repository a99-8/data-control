# 🧩 CSV Injector & Scraper Extension (`data-control`)

إضافة متصفح حديثة ومتقدمة مبنية باستخدام **WXT Framework** و **React** و **TypeScript** ومحرك **HyperFormula**. تتيح الإضافة للمستخدمين إكانية استخراج البيانات (Data Scraping) وحقنها (Data Injection) داخل عناصر صفحات الويب المحددة بشكل آلي ومخصص، مع دعم بناء مجموعات متعدّدة (Groups) وقواعد تحقق ديناميكية باستخدام صيغ Excel الحسابية والشديدة المرونة.

---

## 🚀 المميزات الرئيسية

- **محرك تقييم القواعد الحسابية (HyperFormula Engine):** استبدال التحقق التقليدي المعتمد على JSON بمحرك الصيغ Excel تقييم شرطي ديناميكي لدعم الشروط المركبة مثل (`IFS`, `IF`, `OR`, `AND`) والمقارنة المباشرة بين قيم الحقول أو مع القيمة المستخرجة `VALUE`.
- **لوحة التحكم الشاملة (Options Page):** إدارة المجموعات، إدخال محددات عناصر الـ DOM (Selectors)، كتابة الصيغ الحسابية والقواعد للحقول.
- **القائمة المنبثقة السريعة (Popup Menu):** تنفيذ سريع لأوامر الكشط (`SCRAPE_DATA`)، الحقن (`INJECT_DATA`)، فتح اللوحة الجانبية، أو نسخ البيانات.
- **اللوحة الجانبية التفاعلية (Side Panel):** فحص الحقول والمسح المباشر لعناصر DOM (`SCAN_INPUT_FIELDS`) وترتيبها وتصدير البيانات إلى ملفات CSV.
- **أداء فائق للـ Content Script:**
  - كشط وحقن البيانات بسلاسة.
  - مطابقة الـ Labels لحقول الإدخال للوصول إلى أداء زمني أقصى مقداره **$O(N)$**.
  - دعم التفاعل مع Shadow DOM باستخدام مكتبة `query-selector-shadow-dom`.
- **دعم متعدد اللغات (i18n):** دعم الكامل للغة العربية والإنجليزية وتغيير اتجاه الصفحة تلقائياً (RTL / LTR).

---

## 💡 كيفية كتابة شروط التحقق والربط (HyperFormula Rules)

يتم كتابة الشروط في خانة **الشروط** بدلاً من صيغ JSON القديمة، مع استخدام المعرف الخاص بالحقل (مثل `fld_1` أو `fld_2`) أو الكلمة المفتاحية `VALUE` للتحقق من قيمة الحقل نفسه:

- **استخدام دالة IFS المتعددة:**
  ```excel
  =IFS(fld_2 = "شقة", "جزء من العقار", fld_2 = "دور", "جزء من العقار", TRUE, "مبنى مستقل")
  ```
